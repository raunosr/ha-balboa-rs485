# Integration icon

Original project illustration, generated with the built-in image generation tool
on 2026-09-05. It is not an official Balboa or Home Assistant logo. The selected
PNG is bundled at `custom_components/balboa_rs485/brand/icon.png`; supported HA
versions (tested on 2026.8.3) serve it locally. No remote image host is required
at runtime. The same icon appears in the public repository and HACS README.

Final generation prompt:

> Use case: logo-brand. Asset type: square Home Assistant custom integration icon
> for Balboa RS485, an independent local hot-tub integration. Create one original
> premium, compact spa symbol: a softly sculpted hot-tub bowl with a clean water
> surface and rising warm steam, subtly suggesting connected control. Elegant
> modern app-icon illustration, strong silhouette, balanced negative space,
> readable at 48 px. Single centered mark, generous even padding, no text, no
> letters, no wordmark, no official Home Assistant or Balboa logos, no watermark,
> no mockup presentation. Genuinely transparent background, preserve alpha.
> Square composition, polished but restrained, suitable for both light and dark
> interfaces.
